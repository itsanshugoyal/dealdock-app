# Reply desk — single product direction

Open `index.html` using the repository's local prototype server. This is an interactive, fictional workspace, not the production Next.js app. It makes no network requests, stores no messages, and resets on refresh.

The direction starts with the buyer's actual question. An offer-based estimate and its reasoning sit alongside an editable reply. Explicit approval is a deliberate action, uncertain classification has a separate human-review flow, and only user-confirmed sales reach the revenue record.

Try the complete loop: edit Meera's reply → approve the local simulation → open Waiting → record a confirmed sale → inspect Revenue → export the fictional ledger. Review decisions, search, estimates, draft restoration and mobile navigation work. No Instagram or billing integration is claimed by this prototype.

Typography uses the existing licensed Geist asset in `./assets/`; its license is retained in `./FONT-LICENSE.txt`. No image generation or external visual assets are used.
